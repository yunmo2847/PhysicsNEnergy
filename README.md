# SOFAR 해저 음향 실험실

자유탐구 발표 「바다는 소리를 어떻게 가두는가」를 직접 실험해 보는 웹 시뮬레이션입니다.

| 정거장 | 내용 |
|---|---|
| ST.01 음속 측정 | 프로브를 내려 깊이별 음속 기록, 가장 느린 1000 m 찾기 |
| ST.02 파면이 도는 원리 | 위아래 음속 차이 → 파면 회전 → 원운동 (r = v₀/k) |
| ST.03 발사각 실험 | 몇 도까지 1000 m에 갇히는지 (원운동 예측 13.4°, 시뮬레이션 13.0°) |
| ST.04 도착 경주 | 0·4·8·12° 소리의 200 km 도착 시간, Δt 검증 |
| ST.05 해저 탐사 | 음향측심으로 깊이 계산, 수면 음속 vs 깊이별 보정 |

## 실행
`index.html` 하나로 동작합니다(외부 라이브러리 없음, 글꼴만 Google Fonts). 브라우저로 바로 열어도 됩니다.

## GitHub Pages로 배포
1. 이 브랜치를 기본 브랜치(main)에 병합
2. 저장소 **Settings → Pages → Build and deployment**
3. Source: **Deploy from a branch**, Branch: **main** / **/(root)** → Save
4. 1~2분 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 접속

## 파일
- `index.html` — 배포용 완성 페이지
- `sofar-lab/artifact.html` — Claude 아티팩트 원본(같은 내용, 문서 머리 부분만 없음)

모든 수치는 발표의 예시 음속 프로필(수면 1520 · 1000 m 1480 · 4000 m 1530 m/s) 기준입니다.
